프로세서 구조
CU(control unit)

레지스터: 프로세서 내부에서 데이터를 일시적으로 보관하는 기억 장치, Flip-flop와 Latch로 구성됨
- 범용 레지스터: 프로그램 또는 데이터 처리에 필요한 작업을 수행하기 위해 사용
- 제어용 레지스터: 프로그램이나 프로세서 제어, PC(program counter)
- 상태 레지스터: 프로세서의 상태를 나타냄
연산 장치 (ALU: Arithmetic & Logic Unit)
- 데이터에 대한 수학적 연산 수행
- 연산 결과를 상태 레지스터 또는 Flag 레지스터에 결과 기록(Carry 발생, Overflow 발생, ...)

제어 장치 (CU: Control Unit): 명령어를 해석하고 실행, 내부 데이터 흐름 제어
명령어 레지스터 -> 명령어 해독기 -> 제어 신호 발생기

버스

SoC (System on Chip)
- 여러 개의 반도체 부품이 하나로 집적되는 기술 및 제품
- 메모리, I/O 장치를 포함한 시스템 기능을 칩 하나에 구성

명령어 집합(Instruction Set)에 따른 프로세서 구조
- CISC (Complex Instruction Set Computer) 다양한 명령어-> 복잡, i386
- RISC (Reduced Instruction Set Computer) 단순, ARM

| 구분  | CISC                              | RISC                                                   |
| --- | --------------------------------- | ------------------------------------------------------ |
| 명령어 | 복잡<br>clear 0x1000<br>load r1, #5 | 단순<br>xor r1, r1 //0<br>store r1, 0x1000<br>add r1, #5 |
| 특징  | 메모리 참조 연산                         | Load/Store 구조                                          |
| 성능  | 낮다                                | 높다                                                     |
배터리 소모를 생각하면 RISC가 유리, 메모리를 아끼려면 명령어의 수를 줄이기 위해(다양한 명령어가 있으므로 명령어는 줄일 수 있음) CISC

메모리 시스템 구조
- MMU (Memory Management Unit)
	- Address translation: Virtual → Physical, Memory protection
- 메모리 제어기 (Memory Controller)
- Cache
	- Write-Through: CPU가 특정 주소에 데이터를 Write하는 경우, 해당 데이터가 Cache에 존재하는 경우 Cache와 외부 메모리에 동시에 Write 동작 수행
	- Write-Back: CPU가 특정 주소에 데이터를 Write하는 경우, 해당 데이터가 Cache에 존재하는 경우 Cache 메모리에만 Write 동작 수행. 해당 Cache가 replace될 때 외부 메모리에 Write 동작 수행
- Address Bus
	-  1KB 메모리를 구분하기 위해서는 10개의 address 신호선 필요(1KB = $2^{10}$)

CPU(64K), ROM(32K), RAM(32K)

I/O 장치
- I/O-Mapped
메모리 영역과는 별도로 전용 주소 할당이 필요 -> 메모리 엑세스 명령과 I/O 엑세스 명령어를 구분(같은 주소를 가질 수 있기 때문에)
- Memory-Mapped
메모리 영역의 일부를 I/O 장치로 사용 -> 따로 명령어를 구분할 필요가 없음

입/출력 장치의 자원 관리
- Polling
	- 장치의 상태를 지속적으로 검사하는 전송 제어 방식
	- 입/출력 장치의 연결 여부 및 데이터 전송 요청 및 종료 검사
- interrupt
	- 프로세서는 일련의 처리를 수행하고, 주변 장치에서 입/출력 처리 동작이 필요한 경우 프로세서에게 현재 진행중인 명령을 멈추고 새로운 동작을 실행하도록 함
- DMA(Direct Memory Access)
	- CPU의 개입없이 입/출력 장치와 기억 장치 사이에 데이터를 전송하는 방식
	- Bus Contention(프로세서가 버스에 접근해서 꼬이는 경우) 해결 필요
인터럽트 제어기

interrupt -> ISR

Interrupt Vector
- ISR (Interrupt Service Routine) 또는 ISR의 위치가 저장된 메모리 공간
- Fixed Interrupt: Interrupt 발생 시 처리할 주소가 지정되어 변경되지 않음
- Vectored Interrupt: 주변 장치가 Interrupt를 처리할 주소 제공

GPIO(General Purpose I/O)
- 하나의 연결 단자를 입력이나 출력으로 고정시키지 않고 선택적으로 사용할 수 있도록 융통성을 높인 범용 입/출력 단자

Bus Handshaking: 다른 시스템 컴포넌트들이 타이밍이 맞지 않으면 문제가 생김. 따라서 이걸 조절할 필요가 있음 -> wait signals 등의 기술을 사용


각 장치들은 정해진 주소에 접근하여 사용한다.
